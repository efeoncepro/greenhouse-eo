# Glosario

- **Agentforce:** familia de capacidades para agentes. No implica que todo proceso CRM deba automatizarse ni autoriza acciones autónomas.
- **Agentforce Service:** nombre vigente que Salesforce usa para Service Cloud; conserva `Service Cloud` cuando sea el nombre contractual o histórico verificable.
- **Data 360:** plataforma de datos de Salesforce para conectar, armonizar, unificar y activar datos. No la presentes como requisito universal de CRM.
- **Org:** instancia lógica de Salesforce. Identifica siempre alias, org ID y tipo de entorno antes de operar.
- **Sales Cloud:** CRM para procesos de ventas, leads, cuentas, contactos, oportunidades, actividad, pipeline y forecast según edición.
- **Salesforce Platform:** capa de metadata, datos, seguridad, automatización, desarrollo e integración sobre la que se extienden las soluciones.
- **Consulting Partner:** track de servicios del Salesforce Partner Program sujeto a aceptación y políticas vigentes. No equivale a reseller.
- **Cloud Reseller / Reseller:** track o autorización comercial para reventa. Debe probarse separadamente.
- **SPPA:** Salesforce Partner Program Agreement; su aceptación y policies aplicables gobiernan la participación.
- **Fit:** correspondencia demostrable entre necesidades, restricciones, capacidad organizacional y solución; no mera preferencia de proveedor.
- **System of record:** sistema autoritativo para un dato o proceso. Defínelo por dominio y campo, no para “todo CRM”.
- **Managed CRM Ops:** operación continua gobernada de adopción, datos, automatización, releases, soporte y mejora; no sólo administración reactiva.
