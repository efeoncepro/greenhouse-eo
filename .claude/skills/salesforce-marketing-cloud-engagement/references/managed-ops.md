# Managed Marketing Operations

Define catálogo, intake, prioridades, SLAs/SLOs, ventanas, approvals, ambientes disponibles, release log, incidentes, escalamiento y RACI. Separa operación recurrente de proyectos y change requests.

## Ritmos

- Diario/semanal: fallos de automatización, journeys, imports, APIs, envíos, deliverability y capacidad.
- Mensual: releases, deuda, datos, permisos, contenido, KPIs, consumo y optimización.
- Trimestral: QBR, roadmap, arquitectura, adopción, riesgos, licencias y coexistencia.

## Controles

Usa mínimo privilegio, doble control para activaciones de alto impacto, test contacts, backups/exports, reconciliación, rollback, audit trail y postmortem proporcional. La operación administrada no autoriza por defecto a lanzar campañas, alterar consentimiento, borrar datos o ampliar permisos.
