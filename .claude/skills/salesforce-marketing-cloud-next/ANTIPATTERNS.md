# Antipatrones

| Antipatrón | Riesgo | Corrección |
|---|---|---|
| “Next reemplaza Engagement” | Pérdida de journeys, canales y operación vigente | Evalúa coexistencia y migra capability por capability |
| Diseñar desde el logo del producto | Compra antes de definir outcome | Parte por JTBD, datos, canal, volumen y operación |
| UI visible = licencia disponible | Sobrecosto o alcance imposible | Verifica SKU, entitlement, permiso y créditos |
| Perfil unificado = opt-in | Incumplimiento y contacto indebido | Modela consentimiento por propósito, canal y jurisdicción |
| Agentforce como promesa autónoma | Resultado no gobernado y consumo incierto | Define grounding, acciones, revisión humana y presupuesto |
| Winter ’27 preview en el SOW | Compromiso sobre función no GA | Excluye preview del alcance contractual y registra observación |
| Migración big-bang | Baja reversibilidad y difícil reconciliación | Usa olas, dual-run acotado y criterios de salida |
| Precio público como TCO | Omite add-ons, mensajes, datos y delivery | Modela licencia, consumo, implementación y operación |
| Activar envíos en una prueba técnica | Impacto real no autorizado | Usa contactos de prueba, supresión y aprobación explícita |
| Vender “IA” sin readiness de datos | Bajo valor y riesgo de confianza | Califica identidad, calidad, consentimiento y casos medibles |
