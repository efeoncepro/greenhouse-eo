# Métricas y scorecards de CX

Cada métrica requiere definición, fórmula, unidad, cohorte, período, denominador, fuente, owner, baseline, target y clasificación `controla | influye | monitorea`.

| Capa | Ejemplos |
|---|---|
| Outcome | TTV, éxito del JTBD, repetición de valor, revenue enabled |
| Experience | esfuerzo, claridad, continuidad, confianza, promesa cumplida |
| Adoption | activation, depth, recurrencia, cobertura de roles, workflow crítico |
| Health | sponsor, multithreading, silencio, drivers, riesgo |
| Operations | SLA, resolución, recontacto, handoff failure, scope variance |
| VoC | cobertura, time-to-insight, loops cerrados, reincidencia, impacto |
| Commercial | GRR, NRR, logo retention, renewal, expansion, downgrade, churn |
| AI | precisión, containment, handoff, reversibilidad, FP/FN |
| Equity | esfuerzo diferencial, exclusión, idioma, accesibilidad, autonomía |

Para SaaS/servicios separa: `GRR = (starting recurring revenue - contraction - churn) / starting recurring revenue`; `NRR = (starting recurring revenue - contraction - churn + expansion) / starting recurring revenue`; `logo retention = logos retained / starting logos`. Declara si los ingresos son recurrentes, contratados o reconocidos. NPS es señal relacional secundaria, no outcome.
