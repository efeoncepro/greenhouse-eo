# Plantilla — Respuesta a comentario del cliente

> Usar después de aplicar o documentar la decisión y releer el bloque. Adaptar el tono al hilo; no
> responder con una fórmula robótica ni mencionar herramientas, extracción, prompts, APIs o CMS.
> Norma completa: `../modules/18_REVISION_COMENTARIOS_CLIENTE.md`.

## Cuando se acepta el diagnóstico y la solución

```text
Tomamos la observación sobre [problema concreto]. Ajustamos [cambio aplicado] para [resultado editorial].
La sección ahora [cómo cumple encabezado, claridad, voz o dato].
```

## Cuando se acepta el diagnóstico, pero se resuelve de otra manera

```text
Tomamos la observación sobre [problema concreto]. En lugar de [frase o remedio propuesto], aplicamos
[solución] porque [regla editorial, evidencia o criterio SEO/AEO]. Así conservamos [valor útil] y el texto
queda [resultado verificable].
```

## Cuando no corresponde editar todavía

```text
Revisamos la observación. Para ajustar [dato/claim/asset] necesitamos [fuente o decisión faltante], porque
[riesgo concreto de afirmar o publicar sin respaldo]. Dejamos el punto identificado y pendiente de
[owner/confirmación].
```

## Cuando el comentario detecta contenido interno visible

Primero se sanea la versión vigente completa y se relee la página; no se responde al detectar solo una
frase. La respuesta al cliente describe el resultado editorial sin repetir ni justificar el proceso interno:

```text
Tomamos la observación. Revisamos la versión vigente completa y retiramos los elementos que no formaban
parte de la lectura del artículo. El contenido para revisión quedó separado y releído de principio a fin.
```

## Control antes de enviar

- [ ] Nombra la observación, no solo el resultado.
- [ ] Explica la acción o el bloqueo.
- [ ] Si la solución difiere, explica la razón sin ponerse a la defensiva.
- [ ] Cita la regla o el dato en lenguaje editorial, no el proceso interno.
- [ ] Si hubo contenido interno visible, la respuesta se envió solo después del barrido completo y el readback.
- [ ] No usa `listo`, `corregido` o `de acuerdo` como respuesta completa.
- [ ] No marca el hilo como resuelto.
