# Ficha de toma — {producción} · plano {id}

> Plantilla del [método de producción narrativa](../../../../docs/operations/creative-production/EFEONCE_NARRATIVE_VIDEO_PRODUCTION_METHOD_V1.md)
> (paso 7b, §F.6). Una por plano. Los datos se guardan en el archivo de tomas de la producción (`TOMAS.json`) y el
> storyboard canónico se genera desde ahí. Ejemplo: `ai-generations/2026-10-16_byteplus-anuncio-para-cuando/v2-gpt/TOMAS.json`.

| Campo | Contenido |
|---|---|
| Plano y tiempo | id · entrada–salida en la grilla · beat |
| Estado | por generar · lista para borrador · borrador aprobado · final · bloqueada (por qué decisión) |
| Cuadro inicial | de dónde parte el video (si el cuadro clave es el clímax, se genera aparte) |
| Cuadro clave | el momento que cuenta el plano, con el componente de video armado |
| Cuadro final | sólo si empalma con el plano siguiente (corte encadenado, misma posición) |
| Motor y modo | referencias (personajes del motor) · primer cuadro · primer y último cuadro · edición · composición en post |
| Duración | segundos generados (mínimo del motor) · tramo que se usa · margen para el montaje |
| Cámara | eje en la planta · emplazamiento · altura · lente · movimiento y su función |
| Acción | tiempo a tiempo en la grilla: qué se mueve, en qué orden |
| Referencias | cada personaje con su id en el motor · producto · escena sin rostros · arte de pantallas |
| Sonido | diálogo y si necesita sincronía · SFX con causa · música (entra, sigue, se corta) |
| Continuidad | lo que dice la biblia para este plano: estado de cada persona y objeto, luz, miradas |
| Intocable | lo que no puede cambiar (cara, marca, texto, dirección de la acción, eje) |
| Plan B | qué se hace si el motor falla |
| Dificultad | C cámara · F física · I identidad, de 1 a 5 |
| Formato | en qué formato se genera y cómo se derivan los demás |
| Costo | borrador y final estimados; después, el real |
