# Fuentes y alcance de las recomendaciones

Última consulta de la investigación que sustenta esta skill: **2026-09-04**.
Fuentes primarias; las guías vivas requieren reverificación antes de depender de
una opción técnica o versión. Las fechas siguientes son editoriales cuando la
fuente las identifica; «sin fecha visible» no significa que esté desactualizada.

La skill adapta estas fuentes a informes de Efeonce. Sus manifiestos, plantillas,
pruebas de comprensión y reglas de entrega son **recomendaciones operativas
propias**, no una certificación AMEC, IBCS, ISO, WCAG o PDF/UA. Las guías de gobiernos
extranjeros sirven aquí de referencia; no crean obligaciones legales del cliente.

## Material examinado que no es canon final

[AMEC Data Quality Principles](https://amecorg.com/wp-content/uploads/2026/05/AMEC-Data-Quality-Principles.pdf),
portada del 13-05-2026, versión 2, se identifica como borrador para revisión final.
Aunque sea accesible públicamente, no se trata aquí como estándar final ni se
adoptan sus cifras o umbrales de modelos. Las reglas de evidencia de esta skill
se sostienen en las fuentes anteriores y en la experiencia operativa documentada.

## Mantenimiento y uso honesto

Verifica versión vigente antes de afirmar conformidad, requisitos de imprenta o
comportamiento de un renderer. Registra renderer, validador y estándar objetivo
cuando se evalúe accesibilidad. «Inspirado en» y «verificado contra» son estados
diferentes; una captura agradable no acredita integridad, y tags presentes no
acreditan PDF/UA. Los casos de clientes enseñan decisiones, no fijan sus cifras
como normas para los siguientes informes.
