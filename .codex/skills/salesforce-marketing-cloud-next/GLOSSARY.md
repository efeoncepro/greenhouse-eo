# Glosario

- **Marketing Cloud Next:** capacidades de marketing construidas sobre Salesforce Platform con Data 360, disponibles mediante ediciones y accesos contractuales concretos.
- **Growth / Advanced:** ediciones de Marketing Cloud Next; la disponibilidad de una función puede depender de edición, add-on, release y consumo.
- **Salesforce Platform:** capa core de objetos, seguridad, automatización y experiencia Lightning donde opera Next.
- **Data 360:** nombre vigente de la plataforma antes conocida como Data Cloud; fundamento de ingestión, modelado, identidad, segmentación y activación.
- **Marketing Flow:** Flow con elementos de marketing para orquestar acciones, decisiones y mensajes.
- **Agentforce Marketing:** capacidades agentic aplicadas al trabajo de marketing; no prueba una edición, licencia ni disponibilidad determinada.
- **Salesforce Foundations:** entitlement/plataforma base que puede habilitar acceso a capacidades; no implica consumo ilimitado ni todos los productos.
- **Engagement+:** acceso que preserva Marketing Cloud Engagement y añade capacidades de Next según contrato.
- **Account Engagement+:** forma abreviada en esta skill para coexistencia de Account Engagement con capacidades next-gen; confirma el nombre comercial exacto del SKU.
- **Data space:** partición lógica de Data 360 usada por datos y capacidades de marketing.
- **Unified Individual:** perfil resultante de reglas de identidad; no equivale a consentimiento.
- **Entitlement:** derecho contractual o asignación consumible. Se distingue de permiso y capacidad técnica.
- **GA / preview:** disponibilidad general versus función no comprometible. Beta, pilot y developer preview se tratan como preview.
