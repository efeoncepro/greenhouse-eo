# Sistema de experiencia Efeonce

## Precedencia

Usa como canon `docs/context/10_experiencia-cliente.md`, `docs/documentation/client-portal/portal-cliente-customer-experience-end-to-end.md` y el runtime vigente. El documento de OneDrive `Efeonce_Greenhouse_Sistema_Experiencia_v1.docx` y su `Greenhouse_Sistema_Experiencia_Addendum.docx` son evidencia histórica útil, no reemplazan el repositorio.

## Modelo

La experiencia Efeonce combina operación, software, aprendizaje, red y memoria. Greenhouse conecta y hace visible el sistema; no debe crear dependencia opaca. El cliente debe terminar con más capacidad, contexto compartido y memoria utilizable.

## Ocho fases

| Fase | Momento | Evidencia/artefacto esperado |
|---|---|---|
| Onboarding | Ecosystem Tour, acceso y primer valor | portal activo, baseline y objetivos |
| Primera entrega | Feedback Review con benchmarks | entrega, feedback y siguiente decisión |
| Ritmo operativo | updates y retrospectivas | tendencia de valor, riesgos y aprendizaje |
| Tensión | transparencia con datos | causa, plan de recuperación y owner |
| Expansión | siguiente capacidad basada en evidencia | trigger, caso y decisión del cliente |
| Renovación | “Tu año con Efeonce” | memoria de valor, outcomes y plan |
| Referral | testimonio en momento de impacto | permiso y evidencia, no presión |
| Offboarding | cierre profesional y portabilidad | reporte histórico, handoff y acceso retirado |

## Dos dimensiones transversales

- **Stakeholder invisible:** artefactos ejecutivos compartibles, métricas financieras, ROI y claridad de riesgo.
- **Comunidad/aprendizaje:** conversación humana y aprendizaje compartido; cualquier benchmark entre cuentas debe ser anonimizado y autorizado.

El addendum de OneDrive propone como baseline de adopción: completar Ecosystem Tour, login activo post-onboarding, Feedback Review originado desde portal, señal de Pulse por cuenta/trimestre, NPS post-onboarding y captura de testimonios. Trátalos como hipótesis históricas; valida denominadores y estado real antes de fijar objetivos.
