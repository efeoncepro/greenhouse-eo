# Plan de escenas v2 — registro C para ads

## 1. Por qué las tres anteriores están mal (método, no gusto)

`e3` una pila de papeles · `e4` un papel bajo una lupa · `e5` papeles ordenados en una mesa. **Las tres son
papel impreso, para un servicio que habla de motores de respuesta.** Y ninguna tiene protagonista, cuando el
registro C se definió con elenco.

🔴 **La causa es de método: elegí las palancas por conveniencia técnica, no por concepto.** `descarte`,
`instrumento` y `ausencia` las elegí porque sabía que respetaban la reserva de texto y el lecho —
**optimicé para pasar el validador, no para comunicar.** El validador mide que la pieza sea usable; no mide
que diga algo.

## 2. La regla que faltaba: cómo se fotografía «lo digital» acá

El canon prohíbe **paneles azules grandes de fondo**, **lámparas prácticas encendidas** y —en el bloque de
`copiloto`— **interfaces brillantes, circuitos y hologramas**. Así que «digital» no puede ser el cliché de
pantallas encendidas. Pero mirando lo que **sí** funcionó:

| Pieza | De dónde salía la luz digital |
|---|---|
| `d1` la sala vacía | El visor de Codex + un standby pequeño |
| `d2` la lupa | El visor, sobre el aluminio |
| `a2` la proyección | La proyección sobre hormigón |

> ## La luz digital entra por el OBJETO, nunca por el fondo.
> Un visor, una proyección, un reflejo, un standby. Y la **atmósfera** (`bruma`, `polvo`) hace visible el haz
> — que es lo que da aire tecnológico **sin una sola pantalla encendida de fondo**.

## 3. El elenco, por papel narrativo

| Papel | Quién | Estado |
|---|---|---|
| **Los motores que responden** | Codex · Gigi (familia `aeo-*` en producción) · Clawd | ✅ · ⏳ · ✅ |
| **Nosotros** | 🔴 **`nave-efeonce`** — el isotipo en 3D físico, 3 vistas | ✅ **sin usar ni una vez** |
| **Quien opera** | Nexa — 12 ángulos, **8 expresiones**, 21 vestuarios | ✅ expresiones sin usar |
| **El cliente** | Ausente. Ésa es la idea | — |

**`nave-efeonce` es la pieza que faltaba.** El riesgo que yo mismo señalé —«si todas las piezas necesitan una
criatura ajena, el registro no es nuestro»— no se resuelve con bodegones de papel: se resuelve **usando nuestra
propia criatura**.

## 4. Las tres escenas

### E3 · La descalificación — «acá no vamos»

| | |
|---|---|
| **Dice sin titular** | Alguien del otro lado de la mesa te está diciendo que no |
| **Elenco** | **Nexa** (expresión `the-breakdown`, uniforme) + **la nave Efeonce apagada** sobre la mesa |
| **Palanca** | **`pov`** — la cámara ocupa el asiento del cliente, a la altura de los ojos sentado. No es «mira al lente»: **te habla a ti**. Es la palanca exacta para una descalificación: te lo dicen a la cara |
| **Toma** | Seated eye level, 50 mm f/2 |
| **Lo digital** | La pantalla girada hacia el asiento, **en reposo**; su luz rasante sobre la mesa. Nada encendido de fondo |
| **El azul** | El uniforme navy + el reflejo del monitor |
| **Reserva** | Muro sobre ellos; la mesa en primer plano NO sirve de lecho — road case cruzando |

### E4 · Eficiencia de medios — «lo que pasa del motor a tu canal»

| | |
|---|---|
| **Dice sin titular** | Algo viaja desde la máquina hacia nuestro lado |
| **Elenco** | **Codex** (el motor, encendido) + **la nave Efeonce** (nuestro canal) |
| **Palanca** | **`atraviesa`** — un objeto rígido del oficio cruza el cuadro en diagonal, nítido de punta a punta. Aquí es **el cable trenzado que une el motor con el canal**: literal, y da la geometría fuerte que el bloque de impacto pide |
| **Suma** | **`suspendido`** (sin estrenar; dosis 1 de cada 4) — algo congelado en el aire sobre el cable · **atmósfera `bruma`**: el haz se vuelve columna visible |
| **Toma** | Tele corto, altura de mesa, para comprimir la diagonal |
| **Lo digital** | El visor de Codex iluminando el cable · el haz en la bruma |
| **El azul** | La nave navy + el visor |

### E5 · Transparencia — «estoy dentro de mi trabajo»

| | |
|---|---|
| **Dice sin titular** | El trabajo le cae encima a quien lo hace: no hay nada detrás de la cortina |
| **Elenco** | **Nexa** dentro del haz, uniforme |
| **Palanca** | **`proyeccion`** — el trabajo proyectado sobre materia física, la persona **dentro** del haz y el trabajo cayendo sobre sus hombros. El canon ya midió que significa exactamente *«estoy dentro de mi trabajo»* |
| **Suma** | **atmósfera `polvo`** — el haz del proyector se vuelve visible |
| **Lo digital** | La proyección **es** la luz digital sobre materia real. Cero pantallas |
| **El azul** | El haz frío + el uniforme |
| **Ojo** | `proyeccion` pone al sujeto **de espaldas**: en C está permitido (no exige mirada al lente) |
