| Movimiento                       | Uso                                                                                          |
| -------------------------------- | -------------------------------------------------------------------------------------------- |
| `Core`                           | Renovación, expansión o nuevo negocio con un cliente existente.                              |
| `Strategic Bet`                  | Apuesta relevante con una cuenta nueva, incluyendo licitaciones públicas cuando corresponda. |
