## Límites que deben viajar con el expediente

- **Core / InMail:** Julio declaró inicialmente 50; Ajustes y su captura mostraron después 150 disponibles.
  La diferencia no tiene causa verificada; no deducir cuota mensual, reposición o acumulación. No hubo consumo.
- **Canal:** para no conectados, conexión → aceptación → abordaje como ruta habitual; InMail para alta
  relevancia o ventana estratégica con razón individual. Las listas y la configuración no autorizan envíos.
- **Hipótesis del operador:** que muchos contactos valiosos no sean de primer grado sigue siendo una
  suposición explícita; no existe medición de toda su red. La relación se comprueba por persona.
- **Calificación:** UI y perfiles aportan datos profesionales declarados. Ni un cargo ni guardar una lista
  confirman necesidad, intención, presupuesto, autoridad económica, champion o permiso comercial.
- **Entidad:** marca, página de cuenta, holding, filial y persona no son unidades de compra equivalentes.
  LinkedIn 51+ sirve como proxy del piso corporativo de 50; la entidad y su capacidad se validan por caso.
- **Persistencia:** verificado significa los campos o miembros efectivamente releídos. Capturas locales
  ignoradas son apoyo, no prueba de que todos los resultados o perfiles se hayan revisado exhaustivamente.
- **Historial:** HubSpot pidió reautenticación; no se revalidó el CRM ni se creó Contact/Lead/Deal.
  El filtro CRM deshabilitado en Core es una limitación distinta de ese problema de autenticación.
- **Acciones:** ningún mensaje, invitación, InMail, enriquecimiento pagado, CRM, secuencia o alerta recurrente
  nuevo. La consolidación documental y el commit local se informan por separado del estado de LinkedIn.
