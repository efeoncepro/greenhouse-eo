# Antecedentes y formatos preparados

No hay anexos oficiales del oferente en el único PDF publicado: es el requerimiento de la unidad ISP. Se conserva íntegro y no se firma su línea de responsable.

Documentos propios preparados: propuesta técnica, cotización detallada valorizada, plan de trabajo, dossier de muestras, ficha de oferente, formato de orden de trabajo y acta de recepción. Las dos últimas son herramientas de ejecución, no requisitos inventados de admisibilidad.

Respaldos reales: carta SKY firmada y recepción conforme GORE. No se considera acreditado el umbral de cinco años. No se incluye una carta de cliente redactada por Efeonce como si estuviera emitida por el mandante. CV no exigidos en el PDF; no se adjuntan documentos personales innecesarios.
