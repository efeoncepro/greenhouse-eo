## 3. Oferta empresarial de Anthropic: verificada en fuentes oficiales el 2026-10-20

**Team (2 a 150 personas):**
- Asiento estándar USD 20 al mes con pago anual (USD 25 mensual); asiento premium USD 100 anual (USD 125 mensual).
- Incluye Claude Code, Cowork, Design, M365 y Outlook, SSO, administración de conectores y hasta USD 500 al mes en
  créditos de API compartidos.
- Solo se paga con tarjeta.

**Enterprise self-serve (mínimo 20 asientos):**
- USD 20 por asiento al mes con pago anual, **más el uso cobrado a tarifa de API**.
- Agrega SCIM, roles y permisos, auditoría, Compliance API, retención de datos a medida, claves de cifrado propias,
  listas de IP permitidas, configuración apta para HIPAA y Claude Security (beta).

**Enterprise con ventas:** agrega AWS Marketplace, incentivos por consumo comprometido, pruebas, customer success y
facturación con crédito.

**Education, Government y Nonprofit:**
- Education es un plan institucional; no publica precio.
- Claude for Government tiene FedRAMP High y es **solo para EE. UU.**
- Para una institución chilena aplican Enterprise o Claude a través de la nube.

**Claude Platform (API), USD por millón de tokens (entrada / salida):**

| Modelo | Precio |
|---|---|
| Fable 5.1 | $10 / $50 |
| Opus 5.5 | $4 / $20 |
| Sonnet 5.5 | $2 / $10 |
| Haiku 5.5 | $0,10 / $0,50 |

- Batch rebaja un 50 %.
- **Managed Agents** (beta pública desde el 08-04-2026) cuesta USD 0,08 por hora de sesión activa más los tokens.
- La API también se consume en Amazon Bedrock, Google Vertex AI y Microsoft Azure / Foundry.

**Datos y cumplimiento:**
- Por defecto no entrena con los datos del cliente.
- SOC 2 Type II, ISO 27001, ISO 42001, GDPR y CCPA.
- BAA disponible para Enterprise y API.
