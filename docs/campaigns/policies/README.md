# Políticas ejecutables de campaña

Contratos de composición versionados, ligados a la decisión de campaña; no contienen imágenes ni sustituyen el brief y la dirección editorial de OneDrive. Los valores de color pertenecen a AXIS.

- [CMP-004-color-v1.json](CMP-004-color-v1.json): política candidata de composición de CMP-004; [CDR-010](../decisions/CDR-010-cmp004-agencia-creativa-premium.md). La adopción del método está autorizada; los tratamientos renderizados conservan revisión creativa pendiente.

Una pieza fija archivo y SHA-256. Cambiar la política exige revisar la decisión y actualizar/recomponer las referencias; nunca sobrescribir un archivo histórico para cambiar silenciosamente sus consumidores. Para una revisión que deba coexistir, crear otro archivo e ID. Manual y ejemplo: [compositor de CTA](../../operations/EFEONCE_ADVERTISING_CTA_COMPOSITOR_V1.md#20-política-cromática-por-campaña-optativa).
