# Producción visual social para reportes

## Para qué sirve

Esta capacidad convierte un reporte real —por ejemplo, Brand Visibility— en una pieza visual de Instagram que
puede repetirse a escala sin perder evidencia, marca ni legibilidad.

La pieza no intenta mostrar toda la interfaz. Elige una señal visual —score, diagnóstico o hallazgo— y la presenta
como prueba editorial.

## Qué recibe y qué entrega

Recibe un brief, un asset real del reporte, el logo oficial, referencias visuales y el formato de destino.

Entrega:

- una dirección visual seleccionada;
- un post 1080 × 1350 o una familia de variantes;
- un registro de assets y decisiones;
- evidencia de revisión de thumbnail y tamaño real;
- un estado honesto: aprobado, iterar o bloqueado.

## Reglas de experiencia

- El reporte debe ser reconocible como evidencia real.
- La captura no se encierra en una tarjeta decorativa.
- El logo no se repite si ya aparece en el reporte.
- Los datos no se generan ni se reinterpretan.
- El fondo acompaña; no crea una segunda historia.

## Relación con otras capacidades

- `design-studio`: concepto, dirección de arte, composición y auditoría.
- `social-media-studio`: formato, objetivo, comportamiento del feed y derivación social.
- Artifact Composer: catálogo y gramática de composición cuando exista un template compatible.
- `greenhouse-ai-image-generator`: solo para assets generativos autorizados o clean plates; nunca para el frame
  final con datos, UI o logo.
