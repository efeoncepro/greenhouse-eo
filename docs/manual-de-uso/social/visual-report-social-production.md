# Manual: producir un post visual de reporte

## Antes de empezar

Verifica que tienes:

- el asset real del reporte en resolución suficiente;
- el logo oficial;
- la referencia del sistema visual vigente;
- el formato de destino, por defecto 1080 × 1350 para Instagram feed;
- autorización para usar los datos y la captura.

Si la pieza se publicará en más de una red, define desde el inicio la familia de salidas. No asumas que el
master 1080 × 1350 sirve para todas las superficies.

## Pasos

1. Abre la referencia primaria del sistema —en el caso SKY, `08-informe`— y el asset real del reporte.
2. Elige una sola evidencia protagonista: score, diagnóstico o hallazgo.
3. Define 2–3 composiciones antes de editar el archivo final.
4. Prefiere `Score dominante / Reporte abierto` para un post único.
5. Recorta el reporte para que la evidencia sea legible; no reduzcas la pantalla completa a una miniatura.
6. Mantén la proporción del asset. No lo deformes.
7. Elimina marcos, tarjetas, sombras, mockups y decoración que no provengan del sistema visual.
8. Coloca el logo en la retícula solo si el crop no conserva el logo interno del reporte.
9. Exporta a 1080 × 1350 y revisa el resultado en thumbnail y a tamaño real.
10. Genera los derivados necesarios: Instagram 3:4 opcional, LinkedIn enlace 1.91:1, YouTube Community 1:1,
    YouTube thumbnail 16:9 y Shorts/video vertical 9:16.
11. Prueba la pieza en sus superficies: Instagram feed/post/perfil; LinkedIn móvil/desktop; YouTube
    Home/Subscriptions/Watch/Community y Shorts cuando aplique.
12. Si existe clipping, logo duplicado, repetición de métricas, overlay conflictivo o foco ambiguo, marca
    `iterar` y no entregues.

## Checklist de revisión

- [ ] El foco se entiende en tres segundos.
- [ ] El score o hallazgo se lee en miniatura.
- [ ] No hay marco azul ni tarjeta externa.
- [ ] El logo aparece una sola vez.
- [ ] El crop no corta texto o cifras relevantes.
- [ ] No se inventaron métricas, copy o UI.
- [ ] El reporte mantiene contexto suficiente.
- [ ] El fondo no compite con la evidencia.
- [ ] El contenido crítico queda dentro de la zona central protegida.
- [ ] La primera imagen funciona sin caption.
- [ ] Los derivados no fuerzan un recorte o una proporción de otra plataforma.

## Problemas frecuentes

**La captura se ve pequeña.** Recorta una evidencia concreta y aumenta su escala; no muestres todo el dashboard.

**El logo se ve pegado.** Revisa si ya existe dentro del reporte y elimina el logo externo; si hace falta uno,
usa una única posición fija y un tamaño menor.

**La pieza parece una tarjeta.** Elimina borde, radio, sombra y contenedor. Haz que el reporte llegue al borde del
layout o se integre mediante un crop editorial.

**El fondo llama más la atención.** Reduce la textura y el contraste; el reporte debe sobrevivir al test de
entrecerrar los ojos.

## Cierre

Registra el archivo final, la fuente primaria, la dirección seleccionada, las alternativas rechazadas y el veredicto
de QA. No programes ni publiques sin confirmación humana explícita.
