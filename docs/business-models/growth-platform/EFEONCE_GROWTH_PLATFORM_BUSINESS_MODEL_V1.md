# Efeonce Growth Platform Business Model V1

> **Estado:** `Draft` — modelo de hipótesis; no afirmar software revenue, SaaS margin, ARR o PMF.
> **Owner:** Strategy + Product + Finance + Operations

## Thesis

Efeonce combina servicios especializados, software operativo, datos, método y memoria acumulada para
entregar crecimiento como una relación integrada y recurrente. La hipótesis debe demostrar qué parte del
valor escala por sistema y qué parte sigue dependiendo de capacidad humana.

## Model map

| Layer | Current hypothesis | Evidence needed |
|---|---|---|
| Customer | equipos de marketing mid-market/enterprise | ICP/cohort/source |
| Entry wedge | AEO, Search Visibility 360, CRM, creative, web o media | conversion by wedge |
| Delivery | managed/platform-enabled services | RACI, cost-to-serve |
| Revenue | recurring services + projects + platform/usage/IP | Finance classification |
| Retention | capability + memory + transparency + outcome | renewal/expansion evidence |
| Scale | workflows, data, templates, software, partners | standardization/adoption |
| Moat | integrated context and accumulated operational memory | switching/usage evidence |

## Unknowns

- [ ] service/platform revenue separation;
- [ ] product attach rate;
- [ ] active customer workspaces;
- [ ] automation share and human cost per outcome;
- [ ] expansion attributable to cross-sell;
- [ ] product margin separate from delivery margin;
- [ ] implementation/support burden;
- [ ] global repeatability.
